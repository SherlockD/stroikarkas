# Как обновлять контент сайта

> Подробные пошаговые инструкции для редакторов находятся в
> [`docs/README.md`](../docs/README.md). Начинайте работу с этого файла.

Часто меняющиеся материалы находятся в JSON-файлах этой папки:

- `projects.json` — каталог проектов и категории;
- `current-builds.json` — проекты в работе на первом экране;
- `reviews.json` — отзывы;
- `completed-projects.json` — реализованные объекты и видео;
- `construction-updates.json` — фотографии со стройплощадки.

## Общий порядок

1. Добавьте изображение в подходящую папку внутри `assets/projects`.
2. Скопируйте похожий объект в нужном JSON-файле.
3. Укажите уникальный `id` латиницей (например, `house-ivanovo-01`) и замените значения полей.
4. Проверьте запятые: между объектами нужна запятая, после последнего — нет.
5. Оставьте `published: true`, чтобы запись появилась на сайте. Значение `false` скрывает её.
6. Поле `order` задаёт порядок показа внутри раздела.
7. Откройте сайт в VS Code через Live Server и проверьте результат.

Если JSON повреждён или в нём повторяется `id`, сайт покажет сообщение об ошибке только в соответствующем разделе; меню и форма продолжат работать.

Числа в JSON пишутся без пробелов и с точкой: `65.68` и `1380000`. Пути к файлам пишутся через прямой слэш: `assets/projects/house/photo.webp`.

Поля `example: true` отмечают демонстрационные записи. После добавления настоящего материала это поле можно удалить или заменить на `false`.

## Новый проект

Для проекта обязательно заполните:

- `id`, `category`, `code`;
- `area`, `price`, `package`;
- `description` и `features`;
- хотя бы одно изображение в `images`;
- параметры, используемые формой расчёта.

Дополнительные фотографии и планировки добавляются в массив `images`. Для планировки укажите `"fit": "contain"`.

Допустимые категории первого этапа: `house`, `bath`, `gazebo`. Добавление совершенно новой категории требует изменения формы расчёта и интерфейса сайта.

## Изображения

Рекомендуемые форматы — WebP или оптимизированный JPEG/PNG. Для карточек каталога используйте горизонтальные изображения пропорций 4:3. Всегда заполняйте понятный `alt` без слов «картинка» и «изображение».

Не заменяйте общий файл `assets/image-placeholder.png` фотографией конкретного объекта.
