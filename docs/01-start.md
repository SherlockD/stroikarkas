# Начните отсюда

Эта инструкция поможет впервые подготовить компьютер к работе с сайтом. Она написана для Windows и не требует знаний программирования.

Для работы понадобятся только две программы и одно расширение:

- **GitHub Desktop** — получает файлы сайта с GitHub и отправляет готовые изменения обратно;
- **Visual Studio Code**, или **VS Code**, — открывает и редактирует файлы сайта;
- расширение **Live Server** внутри VS Code — показывает проверочную копию сайта на вашем компьютере.

Отдельно устанавливать Git и пользоваться командной строкой не нужно.

## Как устроена работа

Есть три места, которые важно не путать:

- **GitHub** — основная копия проекта в интернете;
- **локальная копия** — папка проекта на вашем компьютере;
- **настоящий сайт** — страница, которую видят посетители.

Сначала GitHub Desktop обновляет локальную копию. Затем вы меняете её в VS Code и проверяете через Live Server. После проверки GitHub Desktop отправляет изменения на GitHub, и настоящий сайт обновляется автоматически.

## Что понадобится до начала

У вас должны быть:

- компьютер с Windows и доступ в интернет;
- учётная запись GitHub;
- право изменять репозиторий `SherlockD/stroikarkas`.

Одной учётной записи GitHub недостаточно. Владелец проекта должен выдать ей право **Write** — право записи. Попросите разработчика добавить вас в репозиторий и примите приглашение от GitHub.

Если GitHub Desktop предлагает создать **fork**, нажмите **Cancel** и обратитесь к разработчику. Fork — это отдельная копия проекта в вашей учётной записи. Для обычного обновления этого сайта она не нужна.

## Шаг 1. Установите GitHub Desktop

1. Откройте [официальный сайт GitHub Desktop](https://desktop.github.com/).
2. Нажмите **Download for Windows**.
3. Откройте скачанный установщик и дождитесь окончания установки.
4. Запустите GitHub Desktop.

### Войдите в GitHub

1. В GitHub Desktop откройте **File → Options**.
2. Выберите раздел **Accounts**.
3. Нажмите **Sign Into GitHub.com**.
4. Нажмите **Continue With Browser**.
5. В открывшемся браузере войдите в нужную учётную запись GitHub.
6. Подтвердите возврат в GitHub Desktop.

Используйте именно ту учётную запись, которой владелец проекта выдал право записи.

### Проверьте имя автора

1. Откройте **File → Options → Git**.
2. Проверьте поля **Name** и **Email**.
3. Если они пустые или там указаны чужие данные, не придумывайте значения — спросите разработчика, что указать.

Эти данные будут подписывать каждое ваше сохранённое изменение.

## Шаг 2. Установите VS Code

1. Откройте [официальную страницу установки VS Code](https://code.visualstudio.com/docs/setup/windows).
2. Скачайте вариант **User Installer** для Windows.
3. Запустите установщик.
4. Оставьте предложенные настройки и завершите установку.
5. Если GitHub Desktop был открыт во время установки, полностью закройте и снова откройте его.

## Шаг 3. Свяжите GitHub Desktop с VS Code

Это делается один раз:

1. В GitHub Desktop откройте **File → Options**.
2. Выберите **Integrations**.
3. В поле **External Editor** выберите **Visual Studio Code**.
4. Нажмите **Save**.

Теперь GitHub Desktop сможет открывать правильную папку проекта в VS Code.

## Шаг 4. Подключите проект

Сначала проверьте, есть ли на компьютере папка `stroikarkas`, внутри которой лежит файл `index.html`.

- Если такой папки нет, выполните раздел [Вариант А. Клонировать проект](#вариант-а-клонировать-проект).
- Если папка уже есть, выполните раздел [Вариант Б. Добавить существующую папку](#вариант-б-добавить-существующую-папку).

Не выполняйте оба варианта. Иначе на компьютере появятся две копии сайта, которые легко перепутать.

### Вариант А. Клонировать проект

**Клонировать** означает один раз скачать с GitHub правильную копию проекта вместе с историей изменений.

1. В GitHub Desktop выберите **File → Clone repository**.
2. Откройте вкладку **URL**.
3. Вставьте адрес `https://github.com/SherlockD/stroikarkas.git`.
4. В поле **Local path** выберите папку, в которой будет храниться проект. Можно оставить папку, предложенную GitHub Desktop.
5. Нажмите **Clone**.
6. Дождитесь окончания загрузки.

Если проект виден во вкладке **GitHub.com**, можно выбрать `SherlockD/stroikarkas` там вместо ввода адреса.

Не выбирайте **Create new repository** и не соглашайтесь на создание fork. Новый репозиторий для этой работы не нужен.

### Вариант Б. Добавить существующую папку

Этот вариант нужен, если правильная копия проекта уже находится на компьютере.

1. В GitHub Desktop выберите **File → Add local repository**.
2. Нажмите **Choose**.
3. Выберите саму папку `stroikarkas`, внутри которой виден `index.html`.
4. Нажмите **Add repository**.

Не нажимайте **Create a repository** или **Publish repository**. Эти кнопки создают новый проект вместо подключения существующего.

Если GitHub Desktop пишет, что выбранная папка не является репозиторием, возможно, это ZIP-архив без истории изменений. Не удаляйте папку. Выполните клонирование в другое место или обратитесь к разработчику.

## Шаг 5. Проверьте правильный проект и ветку

В верхней части GitHub Desktop проверьте:

- **Current repository** — `stroikarkas`;
- **Current branch** — `main`.

Ветка `main` — основная версия сайта. Из неё автоматически обновляется настоящий сайт.

Если указаны другое название проекта или другая ветка, ничего не меняйте и не сохраняйте. Остановитесь и обратитесь к разработчику.

## Шаг 6. Откройте проект в VS Code

1. В GitHub Desktop откройте меню **Repository**.
2. Выберите **Open in Visual Studio Code** или **Open in default editor**.
3. В левой части VS Code должны быть видны `index.html` и папки `assets`, `content`, `docs`.

Всегда открывайте весь проект, а не один отдельный файл.

## Шаг 7. Установите Live Server

Live Server запускает проверочную копию сайта только на вашем компьютере. Посетители настоящего сайта её не увидят.

Установка выполняется один раз:

1. В VS Code нажмите значок **Extensions** слева. Он похож на четыре квадрата.
2. В строке поиска напишите `Live Server`.
3. Выберите расширение **Live Server** от **Ritwick Dey**.
4. Нажмите **Install**.

## Шаг 8. Запустите сайт для проверки

1. В левой части VS Code найдите `index.html`.
2. Нажмите на него правой кнопкой мыши.
3. Выберите **Open with Live Server**.
4. Откроется браузер с адресом вроде `http://127.0.0.1:5500/`.
5. Не закрывайте VS Code, пока проверяете сайт.

После сохранения файла Live Server обычно обновляет страницу сам. Если этого не произошло, нажмите `F5` в браузере.

## Почему нельзя открывать index.html двойным щелчком

При двойном щелчке браузер открывает файл по адресу, начинающемуся с `file:///`. В таком режиме он может запретить странице читать данные из папки `content`.

Внешний вид страницы загрузится, а проекты, отзывы или фотографии могут пропасть. Данные при этом не удаляются.

Правильный адрес локальной проверки начинается с `http://127.0.0.1:` или `http://localhost:` и открывается через Live Server.

## Безопасный порядок каждой работы

1. Откройте GitHub Desktop и выберите проект `stroikarkas`.
2. Убедитесь, что выбрана ветка `main`.
3. Получите свежую версию кнопками **Fetch origin** и, если появится, **Pull origin**.
4. Откройте проект в VS Code.
5. Измените только нужные файлы и сохраните их.
6. Проверьте сайт через Live Server.
7. Вернитесь в GitHub Desktop, внимательно просмотрите раздел **Changes**.
8. Сохраните и отправьте изменения по инструкции [GitHub Desktop и публикация сайта](09-git-and-publishing.md).
9. Проверьте обновившийся настоящий сайт.

Если появляется непонятное сообщение, предложение создать fork, конфликт или кнопка **Force push**, ничего не подтверждайте. Откройте [Решение частых проблем](10-troubleshooting.md).
