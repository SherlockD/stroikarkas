# Начните отсюда

[← Вернуться к списку инструкций](README.md)

Эта инструкция поможет впервые подготовить компьютер к работе с сайтом. Она написана для Windows и не требует знаний программирования.

Если всё уже установлено и проект уже есть на компьютере, переходите к разделу [Как открыть проект в следующий раз](#как-открыть-проект-в-следующий-раз).

## Что вы будете делать

Работа с сайтом состоит из четырёх простых этапов:

1. Получить свежую копию файлов с GitHub.
2. Изменить текст или изображения в VS Code.
3. Проверить результат на своём компьютере.
4. Отправить изменения на GitHub. После этого сайт обновится автоматически.

Несколько слов, которые встретятся дальше:

- **VS Code** — программа, в которой удобно менять файлы сайта.
- **Git** — программа, которая запоминает изменения и помогает не потерять предыдущие версии.
- **GitHub** — сайт, на котором хранится основная копия проекта.
- **Репозиторий** — папка проекта вместе с историей её изменений.
- **Локальная копия** — копия проекта на вашем компьютере.
- **Публикация сайта** — перенос проверенных изменений на работающий сайт. Разработчики также называют это словом «деплой».

## Что понадобится

Перед началом убедитесь, что у вас есть:

- компьютер с Windows;
- доступ в интернет;
- учётная запись GitHub;
- разрешение изменять репозиторий `SherlockD/stroikarkas`.

Важно: одной учётной записи GitHub недостаточно. Владелец проекта должен выдать ей право записи. Попросите разработчика добавить вас в репозиторий и примите приглашение от GitHub.

## Шаг 1. Установите VS Code

1. Откройте [официальную страницу установки VS Code](https://code.visualstudio.com/docs/setup/windows).
2. Скачайте вариант **User Installer** для Windows.
3. Запустите скачанный файл.
4. Оставьте предложенные настройки и завершите установку.
5. Закройте и снова откройте PowerShell, если он был открыт во время установки.

Проверка:

1. Нажмите кнопку «Пуск».
2. Напишите `Visual Studio Code`.
3. Откройте найденную программу.

## Шаг 2. Установите Git

1. Откройте [официальную страницу Git для Windows](https://git-scm.com/install/windows).
2. Скачайте обычный установщик для Windows.
3. Запустите его.
4. Если вы не знаете, что выбрать на очередном экране, оставляйте предложенный вариант и нажимайте **Next**.
5. После установки закройте VS Code и PowerShell, затем откройте их снова.

Проверьте установку:

1. Откройте PowerShell: нажмите «Пуск», напишите `PowerShell` и запустите найденную программу.
2. Выполните команду:

```powershell
git --version
```

Если появилась строка, начинающаяся с `git version`, всё готово. Если Windows пишет, что команда `git` не найдена, откройте раздел [Git не запускается](10-troubleshooting.md#git-не-запускается).

## Шаг 3. Один раз настройте подпись изменений

Git должен знать, кто сделал изменение. Эти команды выполняются один раз на каждом новом компьютере.

Впишите своё настоящее имя и адрес электронной почты, который используется в вашей учётной записи GitHub:

```powershell
git config --global user.name "Ваше Имя"
git config --global user.email "you@example.com"
```

Например:

```powershell
git config --global user.name "Мария Иванова"
git config --global user.email "maria@example.com"
```

Не копируйте имя и почту из примера. Если не знаете, какую почту указать, спросите разработчика.

Этот адрес будет виден в открытой истории изменений. Если вы не хотите показывать личную почту, откройте [настройки почты GitHub](https://github.com/settings/emails), найдите там адрес вида `...@users.noreply.github.com` и укажите его вместо личного.

## Шаг 4. Впервые скачайте проект

Скачивание проекта вместе с его историей называется **клонированием**. Этот раздел нужно выполнить только один раз.

Откройте PowerShell и по очереди выполните команды:

```powershell
$projectFolder = Join-Path ([Environment]::GetFolderPath('MyDocuments')) 'Sites'
New-Item -ItemType Directory -Path $projectFolder -Force | Out-Null
Set-Location -LiteralPath $projectFolder
git clone https://github.com/SherlockD/stroikarkas.git
Set-Location -LiteralPath (Join-Path $projectFolder 'stroikarkas')
code .
```

Что произойдёт:

- в папке «Документы» появится папка `Sites`;
- внутри неё появится папка `stroikarkas`;
- VS Code откроет весь проект.

Если команда `code .` не сработала, откройте VS Code обычным способом, выберите **File → Open Folder** («Файл → Открыть папку») и откройте папку `Документы\Sites\stroikarkas`.

Не скачивайте проект через зелёную кнопку **Code → Download ZIP**. ZIP-архив не содержит нужной истории Git, и отправить изменения обычным способом из него не получится.

## Как открыть проект в следующий раз

Самый простой способ:

1. Откройте VS Code.
2. Выберите **File → Open Folder** («Файл → Открыть папку»).
3. Откройте `Документы\Sites\stroikarkas`.
4. В левой части VS Code должен быть виден файл `index.html` и папки `assets`, `content`, `docs`.

Можно открыть проект и через PowerShell:

```powershell
Set-Location -LiteralPath (Join-Path ([Environment]::GetFolderPath('MyDocuments')) 'Sites\stroikarkas')
code .
```

Всегда открывайте папку `stroikarkas` целиком, а не один отдельный файл.

Чтобы читать инструкции без браузера, откройте в VS Code файл `docs/README.md` и нажмите `Ctrl+Shift+V`. Откроется аккуратно оформленный просмотр, в котором можно нажимать ссылки на главы.

## Шаг 5. Установите Live Server

Live Server запускает проверочную копию сайта только на вашем компьютере. Посетители настоящего сайта её не увидят.

Установка выполняется один раз:

1. В VS Code нажмите значок **Extensions** («Расширения») слева. Он похож на четыре квадрата.
2. В строке поиска напишите `Live Server`.
3. Выберите расширение **Live Server** от **Ritwick Dey**.
4. Нажмите **Install** («Установить»).

## Шаг 6. Запустите сайт для проверки

Основной способ — Live Server:

1. В левой части VS Code найдите `index.html`.
2. Нажмите на него правой кнопкой мыши.
3. Выберите **Open with Live Server**.
4. Откроется браузер с адресом вроде `http://127.0.0.1:5500/`.
5. Не закрывайте VS Code, пока проверяете сайт.

После сохранения файла Live Server обычно обновляет страницу сам. Если этого не произошло, обновите страницу клавишей `F5`.

### Запасной способ через PowerShell

Используйте его, только если Live Server не запускается и на компьютере уже установлен Python.

1. Откройте в VS Code меню **Terminal → New Terminal** («Терминал → Новый терминал»).
2. Убедитесь, что в строке терминала указан каталог `stroikarkas`.
3. Выполните:

```powershell
py -m http.server --bind 127.0.0.1 8000
```

4. Откройте в браузере [http://localhost:8000/](http://localhost:8000/).
5. Пока вы проверяете сайт, терминал должен оставаться открытым.
6. Чтобы остановить сервер, вернитесь в терминал и нажмите `Ctrl+C`.

Часть `--bind 127.0.0.1` разрешает открывать эту проверочную копию только на вашем компьютере.

Если команда `py` не найдена, вернитесь к Live Server. Устанавливать Python только ради проверки сайта не обязательно.

## Почему нельзя просто дважды нажать на index.html

При двойном щелчке браузер открывает файл по адресу, начинающемуся с `file:///`. В таком режиме браузер из соображений безопасности может запретить странице читать файлы из папки `content`.

В результате внешний вид страницы может загрузиться, а проекты, отзывы и фотографии — не появиться. Это не означает, что данные пропали.

Правильный адрес локальной проверки начинается с:

- `http://127.0.0.1:...` при использовании Live Server; или
- `http://localhost:8000/` при использовании команды Python.

## Безопасный порядок каждой работы

1. Выполните `git status --short`. Перед началом новой работы команда не должна ничего показать.
2. Если команда показала хотя бы один файл, остановитесь и откройте [памятку по проблемам](10-troubleshooting.md#git-pull-не-выполнился).
3. Если список пуст, получите свежую версию командой `git pull --ff-only origin main`.
4. Измените только нужные файлы.
5. Сохраните их сочетанием `Ctrl+S`.
6. Запустите сайт через Live Server и всё проверьте.
7. Отправьте изменения по инструкции [Git и публикация сайта](09-git-and-publishing.md).
8. Проверьте обновившийся настоящий сайт.

Если результат неожиданен или команда показывает непонятную ошибку, ничего не удаляйте и не пробуйте случайные команды из интернета. Откройте [Решение частых проблем](10-troubleshooting.md).
