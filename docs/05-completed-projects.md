# Как менять раздел «Реализованные проекты»

[← Вернуться к списку инструкций](README.md)

## Что изменяет эта инструкция

В разделе **«Реализованные проекты»** показываются уже законченные объекты. Здесь можно разместить:

- карточку с фотографией готового объекта;
- карточку с видеообзором.

Фотография и видео имеют разные поля. При добавлении копируйте запись такого же типа: фотографию с фотографии, видео с видео.

## Где находятся данные и файлы

- Список готовых объектов: `content/completed-projects.json`.
- Новые фотографии и обложки рекомендуется хранить в папке `assets/completed-projects/`.

Если папки `assets/completed-projects/` ещё нет, создайте её при добавлении первого файла.

Примеры понятных имён:

```text
assets/completed-projects/house-skt-82-medvedevo.webp
assets/completed-projects/house-skt-82-video-cover.jpg
```

Используйте маленькие латинские буквы, цифры и дефисы, без пробелов. В JSON путь пишется с прямыми слэшами `/`, без диска `C:`, без первого слэша и без обратных слэшей.

Если фотография уже используется в каталоге и подходит для готового объекта, можно сослаться на существующий файл, например `assets/projects/house/skt-65-cover.webp`. Не заменяйте такой общий файл, если старая фотография должна остаться в каталоге.

## Как подготовить фотографию готового объекта

Для карточки с фотографией:

- рекомендуемый размер — **1448 × 1086 пикселей**;
- пропорции — **4:3**;
- лучший формат — **WebP**;
- можно использовать JPEG (`.jpg`);
- рекомендуемый вес — **до 500 КБ**.

Сайт заполняет изображением всю рамку. Держите дом, баню или беседку ближе к центру, потому что края могут немного обрезаться.

## Как подготовить обложку видео

Для обложки видео:

- рекомендуемый размер — **1280 × 720 пикселей**;
- пропорции — **16:9**, как у обычного видео;
- формат — WebP или JPEG;
- рекомендуемый вес — **до 300 КБ**.

Не размещайте важный текст и логотип точно по центру: там находится круглая кнопка запуска. В правом нижнем углу сайт показывает длительность, поэтому важные детали лучше туда не ставить.

## Поля карточки с фотографией

| Поле | Что писать |
| --- | --- |
| `id` | Уникальное служебное имя латиницей: `completed-skt-82`. Только маленькие буквы, цифры и дефисы. |
| `type` | Для фотографии строго `photo`. |
| `title` | Название объекта, например `Дом с террасой`. |
| `status` | Короткая подпись, например `Построен в 2026 году · Медведево`. |
| `image.src` | Путь к фотографии. |
| `image.alt` | Короткое описание того, что видно на фотографии. |
| `published` | `true` показывает карточку, `false` скрывает её. |
| `example` | Служебная пометка демонстрационного материала. Посетитель её не видит. Для настоящего объекта ставьте `false` или удалите строку. |
| `order` | Порядок показа. Меньшее число показывается раньше. |

## Поля карточки с видео

| Поле | Что писать |
| --- | --- |
| `id` | Уникальное служебное имя латиницей, например `skt-82-video`. |
| `type` | Для видео строго `video`. |
| `title` | Название объекта или видеообзора. |
| `status` | Короткая подпись, например `Готовый дом · 2 минуты 10 секунд`. |
| `label` | Короткая метка над названием, обычно `Видеообзор`. |
| `cover` | Путь к подготовленной обложке 16:9. |
| `coverAlt` | Описание обложки, например `Готовый дом СКТ-82 с террасой`. |
| `url` | Обычная ссылка на страницу видео. Она откроется в новой вкладке, если встроенный просмотр недоступен. |
| `embedUrl` | Специальная ссылка на видеоплеер. Обычная ссылка сюда не подходит. |
| `duration` | Длительность в виде `2:10`. Это только подпись, сайт не вычисляет её сам. |
| `published` | `true` показывает видео, `false` скрывает его. |
| `order` | Порядок показа среди всех готовых проектов. |

Не меняйте `"schemaVersion": 1`.

### Какие ссылки подходят для `embedUrl`

Сайт разрешает встроенное видео только из следующих плееров:

- RuTube: `https://rutube.ru/play/embed/ИДЕНТИФИКАТОР`;
- YouTube: `https://www.youtube.com/embed/ИДЕНТИФИКАТОР`;
- YouTube без cookie: `https://www.youtube-nocookie.com/embed/ИДЕНТИФИКАТОР`;
- Vimeo: `https://player.vimeo.com/video/ИДЕНТИФИКАТОР`.

Ссылка должна начинаться с `https://`.

Для RuTube обычная и встроенная ссылки выглядят по-разному. Например:

```text
Обычная:   https://rutube.ru/video/06d164d7f38cc53c06001636a917710f/
Встроенная: https://rutube.ru/play/embed/06d164d7f38cc53c06001636a917710f
```

Не копируйте обычную ссылку в `embedUrl`. Если `embedUrl` имеет неподдерживаемый адрес, весь раздел «Реализованные проекты» покажет ошибку.

## Как безопасно изменить существующую карточку

1. Откройте `content/completed-projects.json` в редакторе кода, например Visual Studio Code.
2. Найдите запись по строке `"id": "..."` или по `title`.
3. Проверьте `type`: у фотографии должен быть `photo`, у видео — `video`.
4. Меняйте только нужные значения справа от двоеточия.
5. Новый файл сначала добавьте в `assets/completed-projects/`, затем поменяйте путь в JSON.
6. Не меняйте `id` у уже опубликованной записи.
7. Если меняете видео, отдельно проверьте обычную ссылку `url` и ссылку плеера `embedUrl`.
8. Сохраните файл и выполните проверку ниже.

Используйте новое имя для новой фотографии или обложки. Так при ошибке можно вернуть старый путь, а браузер не покажет сохранённую старую картинку из памяти.

## Как добавить готовый объект с фотографией

1. Подготовьте фотографию 4:3 и положите её в `assets/completed-projects/`.
2. В `content/completed-projects.json` найдите список `"items": [`.
3. Скопируйте существующий блок с `"type": "photo"` целиком.
4. Вставьте копию внутри списка `items`.
5. Между соседними блоками поставьте запятую. После последнего блока запятая не нужна.
6. Задайте новый уникальный `id`.
7. Замените `title`, `status`, `image.src` и `image.alt`.
8. Для настоящего объекта поставьте `"example": false`.
9. Укажите свободный `order`.
10. Сначала можно оставить `"published": false`, а после проверки поменять на `true`.

## Как добавить видеообзор

1. Сначала загрузите видео на поддерживаемую площадку.
2. Откройте видео и убедитесь, что оно доступно всем, а не только владельцу аккаунта.
3. Подготовьте обложку 16:9 и положите её в `assets/completed-projects/`.
4. В JSON скопируйте целиком существующий блок с `"type": "video"`.
5. Задайте новый уникальный `id` и замените все подписи.
6. В `url` вставьте обычную ссылку на видео.
7. В `embedUrl` вставьте специальную ссылку плеера из списка выше.
8. В `duration` вручную запишите реальную длительность.
9. Поставьте `"published": false` и сохраните файл.
10. Проверьте раздел локально. Если видео запускается, поменяйте `false` на `true`.

Если нужная видеоплощадка не входит в список поддерживаемых, не подбирайте похожую ссылку наугад. Попросите программиста добавить поддержку площадки.

## Как временно скрыть карточку

Замените:

```json
"published": true
```

на:

```json
"published": false
```

Карточка останется в файле и её можно будет вернуть. Это безопаснее удаления.

## Как изменить порядок

Порядок фотографий и видео общий. Его задаёт поле `order`:

```json
"order": 1
```

Чем меньше число, тем раньше карточка. Используйте разные целые числа. Видео на странице занимает всю ширину, поэтому после изменения порядка обязательно посмотрите весь раздел.

## Полный правильный пример файла

Ниже — полный рабочий пример `content/completed-projects.json` с видео и фотографией. Это образец структуры, а не команда заменить им настоящий файл.

```json
{
  "schemaVersion": 1,
  "items": [
    {
      "id": "kmp-2-video",
      "type": "video",
      "title": "КМП-2",
      "status": "Готовый дом · 1 минута 16 секунд",
      "label": "Видеообзор",
      "cover": "assets/kmp-2-video-cover.jpg",
      "coverAlt": "Готовый каркасный дом КМП-2",
      "url": "https://rutube.ru/video/06d164d7f38cc53c06001636a917710f/",
      "embedUrl": "https://rutube.ru/play/embed/06d164d7f38cc53c06001636a917710f?autoplay=1",
      "duration": "1:16",
      "published": true,
      "order": 1
    },
    {
      "id": "completed-house-ska-60",
      "type": "photo",
      "title": "Дом с мансардой",
      "status": "Готовый дом · Йошкар-Ола",
      "image": {
        "src": "assets/projects/house/ska-60-cover.webp",
        "alt": "Готовый светлый каркасный дом с мансардой"
      },
      "published": true,
      "example": false,
      "order": 2
    }
  ]
}
```

## Как проверить результат

1. Убедитесь, что файл называется `completed-projects.json`, а не `completed-projects.json.txt`.
2. Проверьте, что фотографии и обложки существуют по путям из JSON.
3. Проверьте JSON способом из раздела [«После изменения JSON пропал целый раздел сайта»](10-troubleshooting.md#после-изменения-json-пропал-целый-раздел-сайта). Ошибок быть не должно.
4. Откройте сайт через локальный веб-сервер и нажмите `Ctrl + F5`.
5. Перейдите в раздел «Реализованные проекты».
6. Проверьте порядок, названия, подписи и фотографии.
7. Для каждого видео нажмите кнопку запуска. Видео должно открыться прямо в карточке.
8. Если видео не запускается, откройте значение `url` в новой вкладке и убедитесь, что само видео доступно всем.
9. Проверьте обложку: кнопка запуска не должна закрывать важный текст, длительность должна быть верной.
10. Проверьте раздел в узком окне или на телефоне.

Если весь раздел показывает сообщение «Не удалось загрузить раздел», первым делом проверьте `embedUrl` у опубликованных видео, затем запятые, кавычки и повторяющиеся `id`.

## Частые ошибки

- **Скопировали фото-карточку для видео** или наоборот. У двух типов разные поля.
- **Написали другой `type`.** Используйте только `photo` или `video`.
- **Вставили обычную ссылку в `embedUrl`.** Нужна специальная ссылка `/play/embed/`, `/embed/` или `/video/` для плеера.
- **Использовали неподдерживаемую площадку.** Неверный `embedUrl` ломает отображение всего раздела.
- **Видео доступно только владельцу.** Проверьте его в браузере без входа в аккаунт.
- **Забыли обновить `duration`.** Сайт показывает ровно тот текст, который написан в JSON.
- **Обложка не 16:9.** Она будет обрезана.
- **Важный текст находится в центре или справа снизу.** Его закроют кнопка запуска или длительность.
- **Фотография готового объекта не 4:3.** Края будут обрезаны.
- **Повторили `id`** или использовали в нём русские буквы.
- **Путь содержит `\`, начинается с `/` или не совпадает с именем файла.**
- **Забыли запятую между карточками** или оставили её после последней карточки.
- **Удалили карточку вместо скрытия.** Используйте `"published": false`.
