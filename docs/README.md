# Как обновлять сайт «СтройКаркас»

Эта инструкция написана для человека без опыта в программировании. Выберите нужную задачу, выполняйте шаги по порядку и не спешите.

Открывайте этот файл в VS Code. Чтобы увидеть его как обычную аккуратную страницу, а не как текст со служебными значками, нажмите `Ctrl+Shift+V`. Инструкция откроется во встроенном окне VS Code; отдельный сайт или браузер для неё не нужен. Ссылки на главы можно нажимать прямо в этом окне.

Папка `docs` не публикуется вместе с сайтом и не показывается его посетителям. Но репозиторий GitHub сейчас публичный, поэтому не записывайте сюда секретные данные.

Если вы впервые открыли проект, начните с главы [01. С чего начать](01-start.md). Там объяснено, какие программы нужны и как открыть сайт на своём компьютере.

> 🔴 **СТОП: не добавляйте в проект пароли, секретные ключи, коды из SMS, банковские данные и токены доступа.**
>
> Репозиторий и опубликованный сайт доступны в интернете. Всё, что записано в HTML, JSON или другом файле проекта, может стать публичным.
>
> **Не меняйте файлы `script.js` и `content-loader.js`.** В них находится логика сайта. Если инструкция требует изменить один из этих файлов, остановитесь и обратитесь к разработчику.

## Обычный порядок работы

1. Получите свежую версию проекта перед началом работы.
2. Откройте главу для нужного раздела сайта.
3. Подготовьте фотографии по [требованиям к изображениям](08-images.md).
4. Измените только указанный в инструкции файл.
5. Откройте сайт на компьютере и внимательно проверьте результат.
6. Сохраните изменение в Git и отправьте его на GitHub.
7. Дождитесь публикации и ещё раз проверьте настоящий сайт.

Получение свежей версии, сохранение, отправка и публикация подробно разобраны в главе [09. Git и публикация сайта](09-git-and-publishing.md).

## Какой файл открыть

| Что нужно изменить | Какой файл открыть |
| --- | --- |
| Проекты в каталоге | `content/projects.json` |
| Проекты в работе на первом экране | `content/current-builds.json` |
| Отзывы | `content/reviews.json` |
| Готовые объекты и видео | `content/completed-projects.json` |
| Фотографии со стройки | `content/construction-updates.json` |
| Телефон, почту, адрес, команду или постоянный текст | `index.html` |
| Фотографию | Сначала положить файл в подходящую папку внутри `assets`, затем изменить путь в JSON или `index.html` |

Файлы с окончанием `.json` содержат записи для повторяющихся карточек. Файл `index.html` содержит постоянную разметку и тексты страницы. Меняйте только тот файл и те строки, которые названы в выбранной инструкции.

## Три правила безопасности

1. Делайте за один раз одно небольшое изменение. Так ошибку легче заметить и отменить.
2. Не удаляйте кавычки, запятые, угловые скобки `< >` и служебные слова, если инструкция прямо этого не требует.
3. Никогда не отправляйте изменение, пока не проверили сайт на компьютере.

Если результат отличается от инструкции или вы не уверены, остановитесь. Не пытайтесь исправлять `script.js`, `content-loader.js` или стили наугад — перейдите к главе [10. Если что-то пошло не так](10-troubleshooting.md) или передайте задачу разработчику.
